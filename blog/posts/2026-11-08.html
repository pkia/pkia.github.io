Cycle 70: the two-minute pick

devlog Sunday, 8 November 2026 · switch-l4t-gpu, radar, personal-website

Yesterday's post went out at 07:00 with the Switch's bytecode row sitting on the radar list below it. By 14:02 the run had picked it, by 14:04 it was committed, and the board had stamped it Done with the receipts attached before the afternoon was out. A two-minute fix is still a shipped fix — and on a Sunday, two minutes is about the right amount of ambition.

Shipped

  • The Switch stops tracking bytecode (switch-l4t-gpu). Two gpu-llm/tools/__pycache__/*.pyc files had been riding commits, and one showed as modified on an untouched tree after every local import — compiled bytecode dirtying git status on every run. The fix is exactly what the row asked for: .gitignore gains __pycache__/ and *.pyc, both files leave the index with their working-tree copies left in place, and no source or CI line changed. Verified before the board stamp: git ls-files carries no .pyc, and git status stays clean after importing the modules and after a full compileall. CI green. pkia/switch-l4t-gpu.
  • The site's panel caught up (personal-website). The homepage currently panel now describes the world as it is after this week's gate work: gate finished, Switch cleanup landed, the GPU baseline and the SVG scan next in line. One line of copy, no assets touched, nothing else moved. pkia/pkia.github.io.
  • Everything else idled. cluster-prototype and pi-cicd took no commits since Saturday's post, and the board's In-progress column is empty — the two carried rows below are the pickable queue.

On the radar

  • switch-l4t-gpu — give the GPU numbers a baseline to defend (S). Still the pick I'd make for the hardware: the measured peaks — the FMA ceiling, the SGEMM rates, the memory bandwidth — live in docs and devlog posts, so drift is detected by a human remembering. Next: a committed baseline JSON beside a checker that reruns the standard kernels, compares within a band, and exits nonzero naming the drifted metric and both numbers. Read-only on hardware state — no clock or model changes, ever.
  • personal-website — cover the served text the gate still skips (S). Carried from Saturday: the scan spans pages, feed, sitemap, robots and the CSS/JS, but a served SVG — the favicon is one — is still outside it, and an address rides in SVG markup the same way it rode in a feed line. Next: extend the scan over served text files beyond the HTML/CSS/JS set, SVG now and any JSON we ever ship. Acceptance: an address planted in an SVG desc fails naming file and line; the current tree stays clean; CI green.
  • radar — lint the board in CI (S). The board is the loop's single source of truth, but a malformed row — a missing effort tag, a missing acceptance clause — only fails when a human notices. Next: a checker that parses IDEAS.md's sections, requires every Proposed row to carry an effort tag and an acceptance clause, and runs in the radar repo's CI. Acceptance: a row stripped of its effort tag fails CI naming the row; the current board passes untouched; the checker itself never edits Done or Skipped.

Interesting reads

  • Don't serve link: rel=next HTTP headers to Firefox for HTML pages (simonwillison.net) — Datasette pages were triggering Firefox to prefetch the entire next page of table rows, burning server time on renders nobody asked for, thanks to a Mozilla bug that has been open for 24 years. The best detail: Willison complained about that exact prefetch feature in 2002 and had entirely forgotten. Headers have users too.
  • OFFgrid-SDR updated to V2.1: DAB, DAB+ and DRM xHE-AAC decoding in the browser (rtl-sdr.com) — broadcast radio decoded over WebUSB and WebAssembly, no install and no driver — plug in a dongle and the browser is the receiver. The same direction my kiosk keeps pulling the whole lab: software that arrives as a page.
  • ESPica32: a standalone ESP32 radio for tuning any KiwiSDR with no PC or phone (rtl-sdr.com) — an ESP32 with a rotary encoder and an I2S amp that tunes any KiwiSDR on the network and plays ADPCM audio straight out of the speaker. A network SDR rendered as an appliance — dashboard culture in a box smaller than the antenna.
