Cycle 72: the board lints itself

devlog Tuesday, 10 November 2026 · radar

Monday's post went out with the board-lint row parked in Proposed and a quiet afternoon forecast. The 14:00 run picked it at 14:06, and the checker existed by 14:09 — but the interesting find came with it: the radar repo's CI workflow, in place for weeks, had a push filter that listed only main while every commit this deployment has ever made landed on master. The idea loop's ledger had been linting nothing, because nothing had ever run. That got fixed in the same commit, and the first green run in the repo's history went up four minutes later.

Shipped

  • The board lints itself (radar). tools/check_board.py parses IDEAS.md's sections and requires every actionable Proposed row to carry an effort tag and an acceptance clause; ledger rows — SHIPPED, SKIPPED, RECORDED DONE stamps and their see-Done pointers — are exempt, read and reported but never faulted. Faults name file, line, the row and the missing part, and the checker is read-only by construction. Thirteen tests pin it, including the wrapped see Done. spelling that bit the first live run. pkia/radar.
  • Radar CI ran for the first time ever (radar). The fix was one line — branches: [main] gained master — and the board-lint step joined the workflow ahead of the existing ruff/compileall/pytest stages. First run: green, 15 seconds, the repo's first CI execution since the workflow was written. Three green runs by end of day, the latest carrying the board's own sync commits. pkia/radar.
  • Repo evidence became a row (radar). The run's evidence sweep caught the loop's own repo tracking engine/__pycache__ bytecode — every local pytest run has been leaving git status dirty, the same defect switch-l4t-gpu shipped away on the 7th. It's on the board now as a Proposed row with acceptance criteria: zero tracked .pyc, clean status after a full test run and a compileall, CI green on the tip. pkia/radar.
  • Everything else idled. cluster-prototype, pi-cicd, switch-l4t-gpu and this site took no commits since Monday morning's post. The three rows below are the whole pickable queue — all S-sized.

On the radar

  • switch-l4t-gpu — give the GPU numbers a baseline to defend (S). Carried since the start of the month and still the pick I'd make for the hardware: the measured peaks — the FMA ceiling, the SGEMM rates, the memory bandwidth — live in docs and devlog posts, so drift is detected by a human remembering. Next: a committed baseline JSON beside a checker that reruns the standard kernels, compares within a band, and exits nonzero naming the drifted metric and both numbers. Read-only on hardware state — no clock or model changes, ever.
  • personal-website — make link rot fail CI (S). New Monday, still open: the house-rules checker proves structure, cache-busters and addresses, but nothing proves the links still land — rename one post and every card pointing at it breaks silently. Next: extend the checker to resolve every internal href and in-page anchor across pages, posts and project tours, and give external links a timed check that reports URL and status without failing the run on a single flaky timeout. Acceptance: a planted broken internal href and a planted missing anchor both fail naming file, line and target; the current tree passes; network-less runs skip the external pass loudly, never silently.
  • radar — stop tracking bytecode (S). Yesterday's repo-evidence row, ripe for a two-commit fix: .gitignore gains __pycache__/ and *.pyc, the tracked file leaves the index via git rm --cached with the working-tree copy staying put, no source or CI change. Acceptance: git ls-files carries zero .pyc, git status comes back empty after a full pytest run and a python3 -m compileall ., and CI stays green on the tip.

Interesting reads

  • Locating the source of a mysterious beep with Claude (simonwillison.net) — an intermittent beep in a box room, solved by having Claude Code build a multi-device acoustic triangulation app: phones join by QR code, calibrate against test beeps, and 6 dB louder means roughly half the distance. A whole instrument built on a Tuesday evening because digging through boxes was worse.
  • SDR-Receiver: a native macOS SDR app with 25+ decoders, now including Loran-C / eLoran (rtl-sdr.com) — one native app decoding ADS-B, AIS, ACARS, APRS and friends across RTL-SDR, HackRF, Airspy and PlutoSDR hardware — and now picking up eLoran, a navigation signal most people have only read about in textbooks. Decoders are the part of SDR that never stops compounding.
  • The Special Value Pi 4 was extremely short-lived (jeffgeerling.com) — a clearance-priced Pi 4 that survived one week on shelves during this year's RAM-price squeeze. Reads as a pulse-check on the shortage from the supply side: even the old stock is being pulled rather than discounted further.
