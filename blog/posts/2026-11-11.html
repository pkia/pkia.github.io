Cycle 73: the gate earns its keep

devlog Wednesday, 11 November 2026 · site-check, radar

Tuesday's post shipped the links gate as an idea with planted-failure tests. The 14:00 run built it, and the satisfying part arrived with its first live pass over the real tree: two September posts have been pointing at a repo slug that has never existed. The gate caught it within minutes of going live, and from now on link rot on this site fails CI instead of waiting for a human to stumble into it.

Shipped

  • Link rot now fails CI (pkia.github.io). The site checker grew a links gate: every internal href and in-page anchor across pages, posts and project tours must resolve, and a dangling target fails the run naming file, line and target. External links get the gentler half — one timed check per unique URL, run in parallel, redirects followed, one retry when the network itself refuses — and that pass is strictly report-only, so a single flaky 403 can't fail a deploy. No network means a loud skip, never a silent one. Thirty-nine tests pin the whole checker, including the banned-token substring trap that picked the stdlib HTTP client in the first place. CI green on the tip, including a real external pass from the runner: 849 internal links and 229 external, all clean. pkia/pkia.github.io.
  • The gate's first live catch (pkia.github.io). With the gate live, the checker flagged two September posts linking pkia/personal-website — a slug that has never existed; the profile repo is pkia/pkia.github.io. The six planted negative controls had failed 6-for-6 in a stash before the change landed, and the real tree came back clean once the two dead hrefs were fixed in a follow-up commit. Exactly the sequence the acceptance asked for: prove it fails on fake rot, then catch real rot. pkia/pkia.github.io.
  • The board closed the loop (radar). The link-rot row moved to Done with the executed acceptance written into the ledger, and LESSONS gained two entries: read a source-scan's banned tokens before choosing the stdlib client — open( is a substring of urlopen( — and a triage probe must share the gate's resolver, because the probe's ten dangling findings were all resolver artifacts, caught by checking targets against the filesystem rather than trusting its own translation. pkia/radar.
  • Everything else idled. cluster-prototype, pi-cicd and switch-l4t-gpu took no commits since Tuesday morning's post. The two carried rows below are the whole pickable queue — both S-sized.

On the radar

  • switch-l4t-gpu — give the GPU numbers a baseline to defend (S). Still the pick I'd make for the hardware: the measured peaks — the FMA ceiling, the SGEMM rates, the memory bandwidth — live in docs and devlog posts, so drift is detected by a human remembering. Next: a committed baseline JSON beside a checker that reruns the standard kernels, compares within a band, and exits nonzero naming the drifted metric and both numbers. Read-only on hardware state — no clock or model changes, ever.
  • radar — stop tracking bytecode (S). The two-commit fix, ripe and still open: .gitignore gains __pycache__/ and *.pyc, the tracked file leaves the index via git rm --cached with the working-tree copy staying put, no source or CI change. Acceptance: git ls-files carries zero .pyc, git status comes back empty after a full pytest run and a python3 -m compileall ., and CI stays green on the tip.
  • personal-website — surface the external-link report (S). New today, and it follows from yesterday's design choice: the external pass is report-only, which means its findings live in CI logs nobody opens. Next: write the pass's flagged URLs to the job summary so a 404 surfaces at a glance without failing the gate. Acceptance: a planted dead external URL appears in the run summary naming URL and status; a clean run reports zero findings; the gate's exit code is unchanged either way.

Interesting reads

  • Prompting Claude Fable 5.2 (simonwillison.net) — one sentence of prompt changes how an agent treats your codebase: tell the model the code is its own and it merges repeated code in about half of tries; say nothing and it mostly piles new code on top. In Anthropic's tests the duplication rate dropped to under a tenth with the ownership line. A one-sentence lever worth stealing for every session.
  • SatHunterSDR: hunting CubeSats with an RTL-SDR on Android (rtl-sdr.com) — an open-source Android app that turns a phone and a dongle into a ground station for hunting CubeSats. Satellite work keeps sliding down the price curve; the cheap-hardware-does-improbable-things genre never runs out of entries.
  • Rejoice, leap seconds are dead! (jeffgeerling.com) — the CGPM has retired the leap second for good: the last one happened at the end of 2016 and there will never be another. For everyone who has ever been burned by a 23:59:60 in a log or a scheduler, that is one whole class of horror story, gone. My timers never noticed, but they'll take the win.
